> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Selesaikan sisa temuan hardening audit (R11-R18) yang diverifikasi MASIH VALID pada 2026-08-14 — schema drift, window data kosong, publisher share hardcode, backoff NameError, multi-provider asks, nginx mode, systemd daemon.

**Architecture:** Backend monolith Flask (`backend/app.py`) + CLI sync (`backend/full_sync.py`) + daemon auto-pricing (`scripts/auto_pricing.py`), semua konek ke PostgreSQL `upstream`. Fix: (1) modul schema bersama `backend/db_schema.py` di-import kedua backend (anti-drift), (2) transaksi delete+insert asks satu transaksi, (3) helper `publisher_share_pct()` dari DB dipakai semua titik hardcode 0.80, (4) perbaikan backoff NameError + iterasi semua provider, (5) chmod nginx, (6) pasang systemd user unit.

**Tech Stack:** Python 3.12 (Flask, waitress, psycopg), PostgreSQL 17, nginx, systemd user unit, VPS 82.25.62.204 (gamesim, root via faiz-prod), inferhub.dev API.
